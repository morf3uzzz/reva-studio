## External tools and artwork

FFmpeg/ffprobe are not redistributed in this release. Users install those tools
separately, under the licenses supplied with their chosen distribution.

The app does not redistribute extracted Screen Studio/macOS wallpapers,
proprietary icon fonts, cursor artwork or recorded mouse sounds. Legacy setting
IDs are retained for document interoperability; the actual built-in assets are
generated by REVA's own script. System fonts are resolved on the user's Mac and
are not copied into this repository or release.

Unsplash photos, when explicitly downloaded by a user, retain their provider
attribution and terms. No Unsplash photographs or API credentials are bundled.
