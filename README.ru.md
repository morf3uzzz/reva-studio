<p align="center">Запись экрана и монтаж — локально на вашем Mac.</p>
<p align="center"><a href="https://github.com/morf3uzzz/reva-studio/releases/tag/v0.1.1">Скачать</a> · <a href="README.md">English</a></p>

REVA Studio записывает окно, экран или область и помогает оформить ролик:
анимированные приближения, сцены камеры, титры, курсор, музыка и маски.
Интерфейс доступен на русском и английском.

**Версия 0.1.1 — предварительная.** Реализация готова для дальнейшей проверки;
полная работа всех устройств и разрешений ещё не подтверждена.

## Установка

1. Скачайте **Universal DMG** в [релизе](https://github.com/morf3uzzz/reva-studio/releases/tag/v0.1.1).
   Один пакет содержит Intel и Apple Silicon. Нужна macOS 14 или новее.
2. Установите **FFmpeg и ffprobe**. Если Homebrew уже установлен:
   `brew install ffmpeg`.
3. Перетащите приложение из DMG в «Программы» и откройте его.
4. Выдавайте доступ к экрану, микрофону и камере по мере использования.
   Мониторинг ввода нужен только для записи сочетаний клавиш.

FFmpeg не включён в пакет. Проверяются `/opt/homebrew/bin`, `/usr/local/bin` и PATH.
Приложение не устанавливает программы самостоятельно. Сборка имеет ad hoc подпись
и не нотарифицирована Apple. Если macOS блокирует запуск, используйте штатную кнопку
«Всё равно открыть» в настройках конфиденциальности после проверки источника и SHA-256.
Отключать защиту системы не требуется.

## Возможности

- Запись экрана/окна/области, системного звука, камеры и микрофона; пауза, флаги и заметки.
- Разрезы, trim/restore/join, скорость и громкость по клипам, кадрирование, undo.
- Обычные/автоматические/мгновенные приближения, лупа и сцены камеры.
- Локальная сегментация камеры, следование за лицом, LUT, шумоподавление и звук при перемотке.
- Транскрипт и SRT, монтаж по тексту, титры, музыка, локальная озвучка и ducking.
- Собственные фоны/курсоры/звуки, пресеты, маски, подсветка, OCR и обработка лиц.
- H.264/HEVC/оба файла, ProRes/GIF, Clipboard, исходники и переносимые проекты.
- Локальное улучшение изображения PiperSR 2× CoreML.

Аккаунт и облачная загрузка не нужны. Unsplash — необязательная интеграция с вашим
ключом на время сессии. Speech работает только на устройстве, без скрытого облачного
резервного варианта.

## Что ещё требует проверки

См. [STATUS.md](docs/STATUS.md): реальные камера/микрофон/USB, сочетания клавиш,
распознавание речи, эффекты macOS, Finder/AX и авторизованный Unsplash не объявляются
полностью проверенными. Импорт Screen Studio ограничен известными форматами.
Совпадение закрытых алгоритмов и всех пикселей оригинала не заявляется.

## Разработка

macOS 14+, Apple Command Line Tools, Node 24.18.0+, npm, FFmpeg.

```sh
npm ci
npm run assets
npm run model:fetch
npm run dev
```

```sh
npm run build
npm run build:native
npm test
npm run test:native
npm run release:mac
```

`release:mac` создаёт Universal DMG/ZIP, хеши и отчёт архитектур в `build/releases/`.
Для отдельных сборок: `-- --arch=x64` или `-- --arch=arm64`.
Модель загружается с фиксированной ревизии и проверяется по SHA-256.

В репозитории только приложение: без REA, личных проектов/записей, исследовательских
материалов и извлечённых ресурсов референса. Для Windows нужен отдельный нативный
модуль; текущий релиз поддерживает только macOS.
